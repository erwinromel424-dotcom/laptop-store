## ⚡ Installation

### 1. Clone Repository

```bash
git clone https://github.com/erwinromel424-dotcom/laptop-store.git
```

### 2. Go To Project Folder

```bash
cd laptop-store
```

### 3. Install Dependencies

```bash
composer install
npm install
```

### 4. Copy Environment File

```bash
cp .env.example .env
```

### 5. Generate App Key

```bash
php artisan key:generate
```

### 6. Setup Database

Buat database baru lalu sesuaikan konfigurasi `.env`

```env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=laptop_store
DB_USERNAME=root
DB_PASSWORD=
```

### 7. Run Migration

```bash
php artisan migrate
```

### 8. Run Development Server

```bash
php artisan serve
npm run dev
```
